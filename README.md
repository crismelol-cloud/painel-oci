# Painel de OCIs — Agora Tem Especialistas · Franca/SP

Painel de consulta das Ofertas de Cuidados Integrados (OCI) do Programa Agora Tem
Especialistas, mantido pelo Departamento de Média e Alta Densidade Tecnológica da
Secretaria Municipal de Saúde de Franca/SP.

## Arquivos
- `index.html` — painel principal (52 OCIs, 9 especialidades). Página única, sem dependências externas.
- `ficha-comparativa-cardiologia.html` — comparativo Risco Cirúrgico × Gestão do Pré-operatório.

## Como está publicado
GitHub Pages serve o `index.html` na raiz. Qualquer atualização é só substituir o
arquivo e dar commit — a página no ar muda sozinha.

## Fontes
SIGTAP 09/2026; Portarias SAES/MS e GM/MS (links no rodapé do painel); Resolução SS-16/2025 (Tabela SUS Paulista).

_Base normativa consolidada em set/2026. A legislação do PATE muda com frequência — confirmar a norma vigente na competência antes de decisão de faturamento._
